페이지를 만든 뒤 운영에 필요한 것들

주소, 문의, 검색, 수정이 한 사이트 안에 있습니다.

주소 연결

보유한 도메인을 붙이거나, 기본 주소로 먼저 공개합니다.

문의 폼

이름, 연락처, 내용을 받고 화면에 접수 안내를 보여 줍니다.

검색 정보

제목과 설명을 페이지에 넣어 검색 결과에 사이트가 읽히게 합니다.

메뉴 구성

회사소개, 사업, 제품, 문의처럼 필요한 구역만 나열합니다.

색 변경

기본 색 한 가지를 바꾸면 버튼과 강조 색이 함께 바뀝니다.

문구 수정

화면을 다시 그리지 않고 설정 파일의 문장만 고칩니다.

휴대폰 화면

넓은 화면의 배치가 좁은 화면에서는 세로로 쌓입니다.

템플릿 확장

같은 방식으로 업종별 템플릿을 더 붙일 수 있습니다.

디자인을 직접 그려야 하나요?

아니요. 준비된 템플릿을 고르고 글과 색만 바꾸면 됩니다.

문구는 어디에서 바꾸나요?

템플릿 폴더의 config.json을 수정한 뒤 페이지를 새로고침하면 반영됩니다.

휴대폰용 페이지를 따로 만드나요?

아니요. 화면 너비에 맞춰 메뉴와 카드 배치가 바뀝니다.

지금 볼 수 있는 템플릿은 무엇인가요?

기업 소개형 템플릿을 열어 볼 수 있습니다. 상단의 템플릿 열기로 이동합니다.

어떤 템플릿부터 볼까요?
